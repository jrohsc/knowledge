# 시각화 시스템

먼저 “이 개념을 이해한 사람은 머릿속에 무엇을 그리고 있는가?”를 묻습니다. 인터랙션을 하기 전에도 기본 의미가 보이고, 조작하면 특정 관계 하나가 더 분명해져야 합니다.

## 현재 컴포넌트

| 컴포넌트                | 가르치는 관계                    | 구현                                                  |
| ----------------------- | -------------------------------- | ----------------------------------------------------- |
| `InteractiveFunction`   | 간격 → 평균 변화율 → 순간 변화율 | D3 scale/line + SVG + Δx 슬라이더                     |
| `InteractiveField`      | 질량의 곱 / 거리의 제곱          | SVG 대칭 힘 벡터 + 3개 매개변수                       |
| `ParticleSimulation`    | 국소 분포 / 많은 공간 배치       | 결정론적 SVG 분포 보간; 물리적 충돌 시뮬레이터가 아님 |
| `ProbabilityExperiment` | 한 번의 불확실성 / 장기 상대도수 | D3 line, 독립 의사난수 실험, 최대 5,000회             |
| `CausalFlow`            | 복수 원인과 변화의 단계          | 데이터 기반 합류형 SVG                                |
| `ArgumentMap`           | 주장 / 반례 / 수정 가능성        | 의미에 맞는 들여쓰기와 단계 공개                      |
| `CaveDiagram`           | 그림자 / 사물 / 앎의 조건        | 공간적 SVG와 단계별 주석                              |
| `ProcessDiagram`        | DNA / 전사 / RNA / 번역 / 단백질 | 분자 구조의 단순화와 공간적 과정                      |
| `EvolutionTree`         | 환경에 따른 세대별 형질 비율     | 두 형질의 결정론적 선택 모형                          |
| `PeriodicRelationships` | 주기율표 위치와 바깥 전자        | 처음 18개 원소 선택 + 전자껍질 SVG                    |
| `ScaleComparison`       | 근력 / 연료 / 생산 연결망        | 정성적 산업 구조 비교 SVG                             |
| `ParallelTimeline`      | 같은 시기의 여러 지역            | D3 공통 시간축, 중첩 구간 배치, 기간 이동·확대        |
| `HistoricalTimeline`    | 사건의 순서                      | 데이터 기반 연표. 항목 간격은 시간에 비례하지 않음    |
| `BeforeAfter`           | 변화 전후의 구조                 | 두 열 비교                                            |
| `AnnotatedDiagram`      | 사용자 정의 도해와 설명          | 일관된 figure/figcaption 프레임                       |
| `EquationExplainer`     | 수식과 의미                      | 수식·주석 컨테이너                                    |

컴포넌트 이름은 내부 API입니다. `EvolutionTree`는 현재 분기 계통도가 아닌 자연선택 빈도 모형이며, 확장 시 이름에 기대어 다른 의미를 혼합하지 않아야 합니다. `ScaleComparison`도 정량적 축척을 주장하지 않습니다.

## 확장 방법

- 순수한 문서 도형은 서버 컴포넌트로 작성합니다.
- 입력 상태나 브라우저 API가 필요한 모듈만 `'use client'`를 지정합니다.
- D3는 수학적 scale/path 계산에 사용합니다. DOM 갱신은 React가 소유하여 이중 제어를 피합니다.
- `VisualFrame`을 사용하면 제목·조작부·주석 위치가 일관됩니다.
- MDX에서 사용할 컴포넌트는 `components/visuals/index.ts`에 export합니다.
- 대표 시각화 종류는 `lib/schema.ts`, `HeroVisual.tsx`, `validate-content.ts`에 등록합니다.
- 데이터는 typed props나 `content/` 파일로 분리합니다. 여러 글이 데이터로 같은 구조를 사용할 때만 공통화합니다.

새로운 실제 지리 지도는 위도·경도의 GeoJSON을 별도 콘텐츠 파일에 두고 D3 projection으로 SVG path를 계산하는 모듈로 추가할 수 있습니다. 현재의 평행 연대표를 지리적 거리나 국경처럼 사용하지 않습니다. 현 단계에는 지리 지도나 범용 물리 엔진이 포함되어 있지 않습니다.

## 학습과 접근성

SVG는 `viewBox`를 사용합니다. `role="img"`와 설명적인 `aria-label`을 제공하고 시각화를 요약하는 본문·주석을 함께 둡니다. 색만으로 상태를 구별하지 말고 텍스트·위치·선 스타일을 사용합니다. 버튼은 키보드로 동작해야 하며 슬라이더에는 연결된 label이 필요합니다.

시간축처럼 작은 화면에서 정보를 모두 줄이면 읽을 수 없는 도형은 내부 스크롤 영역을 제공합니다. 페이지 전체에는 가로 넘침이 없어야 합니다. 과도한 자동 애니메이션을 사용하지 않고, `prefers-reduced-motion`을 존중합니다.

테마 색은 `--ink`, `--muted`, `--line`, `--green`, `--gold`, `--blue`를 사용합니다. 분야 이름은 분야별 테마 변수를 사용합니다. 값의 범위와 단위를 화면에 보여주고 모형의 한계는 각주에 숨기지 말고 그림 설명에 적습니다.

## 검증

인터랙션의 값이 변할 때 수치와 도형이 함께 변하는지 확인합니다. 극단값·범위의 끝·초기 상태·리셋을 테스트합니다. 수식의 정의역, 로그나 나눗셈의 0, 확률의 [0,1] 범위 같은 수학적 제약을 명시합니다.

현재 Playwright는 미분 슬라이더, 타임라인, 검색·복습 흐름과 화면 넘침을 검증합니다. axe 검사는 주요 화면의 WCAG A/AA 위반을 찾습니다. 교육적 정확성은 별도의 내용 검토가 필요합니다.

## 큰 그림과 세 장면 삽화

홈페이지 `BigPictureMap`은 네 분야의 관점과 단계별 읽기 경로를 보여줍니다. `content/learning-paths.ts`에서 경로, 글 ID, 연결 이유를 추가합니다. 재생은 사용자가 시작하며 이전·다음·일시 정지를 지원합니다. 화살표는 읽기 순서이며 역사적 인과와 구분합니다.

`<ConceptSketch topic="newton-laws" />`는 세 장면으로 개념을 설명합니다. `content/illustrations.ts`에 제목·장면 설명·해석의 한계를 적고, `components/visuals/SketchDrawing.tsx`에 SVG 장면을 추가합니다. Person, Arrow, Book 등의 기본 요소를 재사용할 수 있습니다. 그림의 의미는 SVG 밖의 한국어 본문으로도 제공하며 색과 움직임에만 의존하지 않습니다. 각 새 글에 동일한 그림을 강제하지 않고 개념에 맞는 구도를 선택합니다.
